# تحديث CORS للسماح بكل النطاقات

الخلفية عامة افتراضياً، ولا تتطلب نطاقاً محدداً. على Railway (أو أي مضيف آخر)، اضبط متغير البيئة التالي صراحةً إذا كانت القيمة الحالية مختلفة:

```text
FRONTEND_ORIGINS=*
```

يجب بعد ذلك نشر إصدار التطبيق الذي يتضمن دعم هذا الخيار. ترجع الاستجابة `Access-Control-Allow-Origin: *`، وتظل `Access-Control-Allow-Credentials` معطلة؛ لذلك لا تُرسل ملفات تعريف ارتباط أو جلسات اعتماد إلى كل المواقع.

**تنبيه:** السماح الشامل يعني أن أي موقع يمكنه استدعاء API من متصفح زائره. لا تستخدم هذا الخيار إذا كان المقصود مجموعة مواقع محددة؛ استخدم قائمة Origins مفصولة بفواصل مثلاً:

```text
FRONTEND_ORIGINS=https://site-a.example,https://site-b.example
```

لا يمكن تغيير متغيرات مشروع Railway الحي من هذه الحزمة وحدها. الملف المنشور لن يتغير قبل تحديث متغير البيئة ونشر الكود الداعم له.
